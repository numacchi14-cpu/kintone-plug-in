# kintone Excel帳票出力プラグイン

複数のkintoneアプリからレコードを取得し、Excelテンプレートの元データ用シートへ書き込んで `.xlsx` を出力するプロトタイプです。

## 現在のプロトタイプ範囲

- プラグイン1本で「テンプレート管理」「帳票出力」を設定画面から切り替え
- 帳票ごとに取得元アプリ設定JSONを保存可能
- 取得元アプリはJSON設定で複数指定可能
- アプリIDから出力フィールド一覧と型を取り込み可能
- テンプレート管理アプリから、紐づく帳票出力アプリの任意フィールドを抽出条件に指定可能
- 出力フィールドの選択、削除、上下移動に対応
- 取得元ごとに複数の抽出条件と並び順を設定可能
- 日付フィールドがないアプリと条件なし全件取得に対応
- 初期Excelテンプレートを自動生成
- 完成版テンプレート添付をテンプレート管理アプリから取得
- 設定シートへ出力条件を書き込み
- 元データ用シートへkintoneレコードを書き込み
- 集計シートの数式・書式は触らず保持
- 基準日は常に実行日の前日を使う
- 帳票出力時は保存済み・手入力の基準日ではなく、その時点の昨日を優先
- 日付抽出条件ごとに月次・年次などの期間ルールを設定可能
- 500件超のレコード取得にカーソルAPIで対応

## セットアップ

```powershell
npm.cmd install
npm.cmd run typecheck
npm.cmd test
npm.cmd run package
```

生成されるzip:

```text
dist/kintone-excel-report-plugin-v0.7.0.zip
dist/kintone-excel-report-plugin.zip
```

`v0.7.0` 付きのzipは履歴確認用、バージョンなしのzipは最新版用です。どちらも中身は同じです。

各バージョンの変更内容は [CHANGELOG.md](C:/Projects/kintone-plug-in/CHANGELOG.md) に記録します。

初回パッケージ時に、kintoneプラグインIDを維持するための秘密鍵が `private/plugin.ppk` に保存されます。このファイルを使って再パッケージすると、kintone上で同じプラグインとしてアップデートできます。

`private/plugin.ppk` は公開・共有・削除しないでください。Git管理対象にも含めません。

## kintone側の使い方

1. kintoneへ `dist/kintone-excel-report-plugin.zip` をアップロードします。
2. テンプレート管理アプリと帳票出力アプリの両方へ同じプラグインを追加します。
3. テンプレート管理アプリ側のプラグイン設定で、モードを `テンプレート管理` にします。
4. 帳票出力アプリ側のプラグイン設定で、モードを `帳票出力` にします。
5. 帳票出力アプリ側では、テンプレート管理アプリID、帳票種類・対象店舗・基準日のフィールドコード、取得元アプリ設定JSONを指定します。

## 利用者向けセットアップ

このプラグインはkintoneアプリのフォームを自動作成しません。先にkintone側で必要なフィールドを作成してください。

### 1. テンプレート管理アプリを作る

最低限、次のフィールドをフォームに追加します。

| フィールド名 | フィールド種類 | フィールドコード |
|---|---|---|
| 帳票ID | 文字列1行 | `report_id` |
| 帳票名 | 文字列1行 | `report_name` |
| 完成版テンプレート添付 | 添付ファイル | `completed_template` |
| 取得元アプリ設定JSON | 文字列複数行 | `sources_json` |

フィールドを追加したら、必ず `アプリを更新` してください。

テンプレート管理アプリのプラグイン設定:

- モード: `テンプレート管理`
- 帳票IDフィールドコード: `report_id`
- 帳票名フィールドコード: `report_name`
- 完成版テンプレート添付フィールドコード: `completed_template`
- 取得元アプリ設定JSONフィールドコード: `sources_json`
- 紐づく帳票出力アプリID: 帳票出力アプリのアプリID

操作手順:

1. テンプレート管理アプリでレコードを追加する
2. `帳票ID`、`帳票名` を入力する
3. 画面上部の `取得元アプリ設定JSONをかんたん作成` を開き、取得元アプリごとに名前、アプリID、Excelシート名を入力する
4. `フィールド一覧を取得` を押し、出力するフィールドをチェックする
5. 必要に応じて全選択、全解除、選択行削除、上下移動で出力列を調整する
6. 抽出条件と並び順を設定する。日付条件では「月初から基準日」「1月1日から基準日」などを選び、日付がないアプリには日付条件を追加しない
7. `JSONをフィールドへ反映` を押し、最初は `完成版テンプレート添付` を空にしてレコードを保存する
8. レコード詳細画面で `初期Excelテンプレート作成` ボタンを押す
9. ダウンロードされたExcelを編集し、集計シートを作る
10. 編集済みExcelを同じレコードの `完成版テンプレート添付` に添付して保存する

### 2. 帳票出力アプリを作る

最低限、次のフィールドをフォームに追加します。

| フィールド名 | フィールド種類 | フィールドコード |
|---|---|---|
| 帳票種類 | 文字列1行、またはドロップダウン | `report_type` |
| 対象店舗 | 文字列1行、またはドロップダウン | `store` |
| 基準日 | 日付 | `base_date` |

フィールドを追加したら、必ず `アプリを更新` してください。

帳票出力アプリのプラグイン設定:

- モード: `帳票出力`
- テンプレート管理アプリID: テンプレート管理アプリのアプリID
- 帳票種類フィールドコード: `report_type`
- 対象店舗フィールドコード: `store`
- 基準日フィールドコード: `base_date`
- 取得元アプリ設定JSON: テンプレート管理レコード側が未入力の場合に使う共通の既定値

`帳票種類` には、テンプレート管理アプリの `帳票ID` と同じ値を入力します。

例:

```text
テンプレート管理アプリ.帳票ID = monthly_actual
帳票出力アプリ.帳票種類 = monthly_actual
```

操作手順:

1. 帳票出力アプリでレコードを追加する
2. `帳票種類`、`対象店舗` を入力し、自動設定された `基準日` を確認する
3. レコードを保存する
4. レコード詳細画面で `Excel帳票出力` ボタンを押す
5. 完成版テンプレートにkintoneデータが書き込まれた `.xlsx` がダウンロードされる

基準日は、前日までの営業実績を対象にするため常に実行日の前日を使います。レコード追加時には昨日の日付を初期表示し、Excel出力時も保存済みの値や利用者が手入力した値ではなく、その時点の昨日をリアルタイムに計算して使い、出力後にレコードへ保存します。

たとえば `2026-07-30` に出力すると基準日は `2026-07-29`、`2026-08-01` に出力すると基準日は `2026-07-31`、`2026-08-03` に保存済みの `2026-07-31` を開いて出力すると基準日は `2026-08-02` になります。

### よくあるつまずき

- レコード追加画面で何も入力できない場合、アプリのフォームにフィールドがありません。フォーム設定で必要フィールドを追加して `アプリを更新` してください。
- レコード詳細画面にボタンが出ない場合、プラグイン設定のモードとアプリ更新状況を確認してください。
- `帳票種類` とテンプレート管理側の `帳票ID` が一致しない場合、完成版テンプレートを探せません。
- フィールドコードを変更した場合は、プラグイン設定画面のフィールドコードも同じ値にしてください。
- 帳票ごとにシート名や取得条件を変える場合は、テンプレート管理アプリの `取得元アプリ設定JSON` に入力してください。

## 取得元アプリ設定JSON

テンプレート管理レコードの `sources_json` に入力すると、その帳票専用の取得元アプリ設定として使われます。

プラグイン設定画面のJSONは、テンプレート管理レコード側が未入力の場合の共通既定値です。

詳しいコピペ例は [SOURCES_JSON_EXAMPLES.md](C:/Projects/kintone-plug-in/SOURCES_JSON_EXAMPLES.md) を参照してください。

テンプレート管理アプリのレコード追加/編集画面では、`取得元アプリ設定JSONをかんたん作成` から簡易フォームでJSONを生成できます。取得元アプリは複数追加、複製、削除できます。

アプリIDを入力して `フィールド一覧を取得` を押すと、ログインユーザーの権限でフォームのフィールド定義を取得します。取得したフィールドはkintoneの型から `text` / `number` / `date` / `datetime` を自動判定します。チェックした行だけJSONへ反映され、上下ボタンの並びがExcelの列順になります。

現在の行形式では正しく出力できないため、テーブル、添付ファイル、関連レコード一覧、グループなどの構造・ファイル系フィールドは自動取り込みから除外し、除外件数を画面に表示します。

主な項目:

- `appId`: 取得元kintoneアプリID
- `sheetName`: Excel内の書き込み先シート名
- `fields`: 出力するフィールドコードと見出し
- `filters`: 抽出条件。対象店舗、基準日から計算する期間、基準日、出力アプリの任意フィールド、固定値を複数指定可能
- `sorts`: 並び順。複数フィールドを指定可能

抽出条件を1行も設定しなければ、その取得元アプリは全件取得します。画面で追加した条件はすべてANDで結合されます。

取得元アプリのフィールドを帳票出力アプリの任意フィールドで絞り込む場合は、`valueFrom: "outputField"` と `outputField` を使います。

```json
{ "field": "店舗ID", "operator": "=", "valueFrom": "outputField", "outputField": "store_id", "valueType": "text" }
```

正式なJSON形式は `filters` / `sorts` のみです。開発初期版の `dateField` / `storeField` / `sort` / `periodRule` / `additionalQuery`、または `valueFrom: "period"` を含むJSONは読み込まず、簡易生成UIでの作り直しを案内します。

日付条件の `dateRule`:

- `sameDay`: 基準日と同じ日
- `previousDay`: 基準日の前日
- `nextDay`: 基準日の翌日
- `baseWeek`: 基準日の週（日曜から土曜）
- `previousWeek`: 基準日の前週
- `nextWeek`: 基準日の翌週
- `baseMonthStart`: 基準日の同月1日
- `baseMonthEnd`: 基準日の同月末
- `monthStartToBaseDate`: 基準日の月初から基準日
- `baseMonth`: 基準日の月初から月末
- `previousMonthStart`: 基準日の前月1日
- `previousMonthEnd`: 基準日の前月末
- `previousMonth`: 基準日の前月
- `nextMonthStart`: 基準日の翌月1日
- `nextMonthEnd`: 基準日の翌月末
- `nextMonth`: 基準日の翌月
- `baseMonthToNextMonthEnd`: 基準日の月初から翌月末
- `baseYearStart`: 基準日の同年1月1日
- `baseYearEnd`: 基準日の同年12月31日
- `yearStartToBaseDate`: 1月1日から基準日
- `baseYear`: 基準日の同年
- `previousYearStart`: 基準日の前年1月1日
- `previousYearEnd`: 基準日の前年12月31日
- `previousYear`: 基準日の前年
- `nextYearStart`: 基準日の翌年1月1日
- `nextYearEnd`: 基準日の翌年12月31日
- `nextYear`: 基準日の翌年
- `sameDayPreviousYear`: 基準日の前年同日
- `sameMonthPreviousYear`: 基準日の前年同月
- `previousMonthPreviousYear`: 基準日の前月の前年同月

## 注意

APIトークンは使わず、ログインユーザーの権限で `kintone.api()` を実行します。Excelの数式はブラウザ側では計算せず、Excelで開いたときの再計算に任せます。

## プラグインをアップデートするとき

kintoneでは、同じプラグインIDのzipだけが既存プラグインの更新として扱われます。プラグインIDはパッケージ時に使う秘密鍵で決まるため、毎回同じ `private/plugin.ppk` を使ってzipを作成してください。

```powershell
npm.cmd run package
```

アップロードするファイル:

```text
dist/kintone-excel-report-plugin-v0.7.0.zip
```

最新版だけを使う場合は、次のファイルをアップロードしても同じです。

```text
dist/kintone-excel-report-plugin.zip
```

注意:

- `private/plugin.ppk` を削除すると、同じプラグインとして更新できなくなります。
- `.ppk` はkintoneにアップロードしません。
- `.ppk` は秘密鍵なので、外部へ渡さないでください。
