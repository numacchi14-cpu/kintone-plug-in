Excel帳票出力 設定

このアプリでの動作モードと、帳票プロトタイプ用のフィールド・取得元アプリを設定します。

説明書を開く

テンプレート管理アプリ

フォームに次のフィールドを作成してから、プラグイン設定でモードを「テンプレート管理」にします。

フィールド名 フィールド種類 フィールドコード
帳票ID 文字列1行 report_id
帳票名 文字列1行 report_name
完成版テンプレート添付 添付ファイル completed_template
取得元アプリ設定JSON 文字列複数行 sources_json
  1. テンプレート管理アプリでレコードを追加します。
  2. 帳票IDと帳票名を入力し、画面上部の「取得元アプリ設定JSONをかんたん作成」を開きます。
  3. 出力アプリの任意フィールドを抽出条件に使う場合は、プラグイン設定で紐づく帳票出力アプリIDを入力します。
  4. 取得元アプリのアプリIDとExcelシート名を入力し、「フィールド一覧を取得」を押します。
  5. 出力フィールドと削除フィールドを行き来させながら、必要ならドラッグまたは上下移動でExcelの列順を整えてJSONへ反映します。
  6. 抽出条件には対象店舗、対象期間、基準日、出力アプリの任意フィールド、固定値を設定できます。日付がないアプリでは対象期間条件を追加しません。
  7. 最初は添付ファイルを空のままレコードを保存します。
  8. レコード詳細画面の「初期Excelテンプレート作成」ボタンを押します。
  9. ダウンロードされたExcelの集計シートを編集します。
  10. 編集済みExcelはレコード詳細画面の「完成版テンプレート添付を更新」から登録します。添付は1ファイルだけにしてください。
  11. 登録後は「テンプレート検証」を押して、出力に必要なシートと列見出しが揃っているか確認します。

帳票出力アプリ

フォームに次のフィールドを作成してから、プラグイン設定でモードを「帳票出力」にします。

フィールド名 フィールド種類 フィールドコード
帳票種類 文字列1行、またはドロップダウン report_type
対象店舗 文字列1行、またはドロップダウン store
基準日 日付 base_date
期間開始、期間終了、出力日時、出力者、出力ファイル名、ステータス 日付、日時、文字列1行など 任意。使う場合だけプラグイン設定で指定
  1. 帳票出力アプリのプラグイン設定で、テンプレート管理アプリIDを入力します。
  2. 取得元アプリ設定JSONに、実データ取得元アプリのID、シート名、フィールドを設定します。
  3. 帳票出力アプリでレコードを追加します。
  4. 帳票種類には、テンプレート管理アプリの帳票IDと同じ値を入力します。
  5. 基準日は常に実行日の前日を使います。出力時も保存済みの値ではなく、その時点の昨日で計算します。
  6. 期間開始・期間終了フィールドを設定すると、基準日の月初から基準日までを自動入力します。
  7. 出力日時・出力者・出力ファイル名・ステータス・出力条件メモフィールドを設定すると、出力後にレコードへ保存します。
  8. 出力前に「出力前チェック」を押すと、テンプレート管理レコード、完成版テンプレート、取得元設定のつながりを確認できます。
  9. レコード詳細画面の「Excel帳票出力」ボタンを押します。

つまずきやすい点

  • レコード追加画面で何も入力できない場合、フォームにフィールドがありません。
  • フォームを変更した後は、必ずアプリを更新してください。
  • 帳票出力アプリの帳票種類と、テンプレート管理アプリの帳票IDは同じ値にしてください。
  • フィールドコードを変更した場合は、プラグイン設定画面のフィールドコードも同じ値にしてください。
  • APIトークンは使いません。ログインユーザー権限でkintone APIを実行します。
  • フィールド一覧を取得できない場合、アプリIDとログインユーザーのアプリ閲覧権限を確認してください。
  • テーブル、添付ファイル、関連レコード一覧など、現在の行出力に非対応のフィールドは一覧取り込み時に除外されます。
  • 取得元アプリ設定JSONが未入力の場合は、プラグイン設定画面のJSONを使います。
  • 完成版テンプレート添付が未登録、または2ファイル以上ある場合は、帳票出力を中断します。

取得元アプリ設定JSON

どのkintoneアプリから、どの条件で、どの列を、Excelのどのシートへ書くかを指定します。

[
  {
    "key": "actual",
    "label": "実績",
    "appId": "99",
    "sheetName": "日別計画実績",
    "tableName": "tbl_actual",
    "fields": [
      { "code": "日付", "label": "日付", "type": "date" },
      { "code": "店舗名", "label": "店舗名" },
      { "code": "実績_総売上", "label": "実績_総売上", "type": "number" }
    ],
    "filters": [
      { "field": "店舗ID", "operator": "=", "valueFrom": "outputField", "outputField": "store_id", "valueType": "text" },
      { "field": "日付", "operator": "between", "valueFrom": "dateRange", "valueType": "text", "dateRule": "monthStartToBaseDate" }
    ],
    "sorts": [
      { "field": "日付", "order": "asc" }
    ]
  }
]

テンプレート管理

帳票出力

取得元アプリ設定 JSON

テンプレート管理レコード側のJSONが未入力の場合に使う共通の既定値です。帳票ごとに変える場合は、テンプレート管理アプリの取得元アプリ設定JSONフィールドへ入力してください。
